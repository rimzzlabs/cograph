# Tracking issue template

Fill every section. Write the prose in Simplified Technical English (see the
[ste](../ste/SKILL.md) skill). Keep the body a truthful snapshot of the current
state; record history as comments.

```markdown
# <short imperative title>

## Goal
What we want to achieve. One or two sentences.

## Context
Why this matters. Background, links, and constraints.

## Tasks
- [ ] First task
- [ ] Second task

## Decisions
Record each decision here as it is made:

- <date> — <decision> — <reason>

## Status
Current state. Update this as the work moves (not started / in progress /
blocked / in review / done).
```
