# RFC template

Fill every section. Write the prose in Simplified Technical English (see the
[ste](../ste/SKILL.md) skill). If a section has nothing, write "None." — do not
delete it.

```markdown
# RFC: <short imperative title>

## Summary
One paragraph. What do we propose, in plain terms.

## Motivation
Why do this now. What problem does it solve. Who is affected.

## Proposal
The design. Be concrete. Use lists and headings. Reference code as `path:line`
when it applies.

## Alternatives
Other options we considered. Why we did not choose them.

## Drawbacks / risks
Costs, trade-offs, and what could go wrong.

## Open questions
Decisions we still need. Mark each one clearly.

## References
Links, related issues, prior art.
```
